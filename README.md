# SCAT前処理ツール

インタビュー逐語録を意味のまとまりごとに分割し、SCAT分析用のExcelファイルに整えるツールです。

処理はすべてブラウザ内で行います。読み込んだ研究データをサーバーへ送信せず、AIモデル、外部API、アクセス解析、クラウド保存も使用しません。

## ワンクリックでダウンロード

[**⬇ SCAT前処理ツールをワンクリックでダウンロード**](https://github.com/SatoruMuro/SCAT-preprocessor/archive/refs/heads/main.zip)

上のボタンを押すと、最新版がZIP形式でダウンロードされます。ZIPを展開し、`dist` フォルダ内の `SCAT-preprocessor-offline.html` をダブルクリックして起動してください。

## ダウンロード方法

通常は、上の「SCAT前処理ツールをダウンロード」ボタンを押すだけです。

リポジトリ全体が必要な場合は、リポジトリ上部の緑色の「Code」ボタンを押し、「Download ZIP」を選択してください。ZIPを展開すると、`dist/SCAT-preprocessor-offline.html` にツール本体があります。

## 起動方法

ダウンロードした `SCAT-preprocessor-offline.html` をダブルクリックし、Chrome、Edge、Firefox、Safariなどのブラウザで開きます。

インターネット接続は不要です。研究データを扱う場合は、GitHub上の画面ではなく、ダウンロードしたHTMLファイルをパソコン上で開いて使用してください。

## 使い方

1. 「逐語録を読み込む」の枠をクリックし、Wordファイル（`.docx`）またはテキストファイル（`.txt`）を選択します。枠へのドラッグ＆ドロップでも読み込めます。
2. 自動検出された発話者を確認します。必要に応じて、発話者名を読点または改行で修正します。
3. 分割の細かさを選び、「意味のまとまりに分割する」を押します。
4. 分割結果を確認し、必要に応じてテキストの修正、行の分割・結合・削除・追加を行います。
5. 「Excelをダウンロード」を押します。
6. 出力されたExcelの「テクスト」列を確認し、SCAT分析の各欄を記入します。

自動分割は句読点、発話者の切り替わり、接続表現、文章の長さに基づく候補です。AIによる分析ではないため、最終的な意味単位は研究者が確認してください。

## 対応ファイル

- 入力：Word（`.docx`）、テキスト（`.txt`）
- 出力：Excel（`.xlsx`）

古いWord形式（`.doc`）には対応していません。Wordで開いて `.docx` 形式に保存し直してから読み込んでください。

## プライバシー

- 読み込んだ文書はブラウザのメモリ内だけで処理します。
- 外部通信はContent Security Policyでも遮断しています。
- ページを閉じると読み込んだ内容は破棄されます。
- AIモデル、外部API、アクセス解析、Cookie、ブラウザ内の永続保存を使用しません。

詳しくは [PRIVACY.md](PRIVACY.md) を参照してください。

## 開発者向け

```bash
npm install
npm test
```

単一HTML版を再生成する場合は、次を実行します。

```bash
npm run build
```

生成物は `dist/SCAT-preprocessor-offline.html` と `dist/index.html` に出力されます。
